## Lorenco Shametaj

**Compiler & real-time systems engineer — Rust / C++.**
I build the low-level layers between models and silicon: lock-free real-time
pipelines, MLIR compiler passes, DSP & low-precision numerics, and
vendor-agnostic hardware runtimes.

### Selected work
- **[NSI](https://github.com/Lorencoshametaj/nsi)** — a complete, std-only,
  vendor-agnostic **real-time neural-I/O runtime** in Rust: lock-free hot path
  (zero heap allocation), a C-ABI driver contract, online DSP + spike sorting,
  and a conformance suite. Runs end-to-end on real Neuropixels data — no
  hardware required.
- **tt-mlir** — contributed a TTIR canonicalization fix to Tenstorrent's
  open-source MLIR compiler ([PR #8912](https://github.com/tenstorrent/tt-mlir/pull/8912)).

### Focus
MLIR / compiler backends · real-time & lock-free systems · SIMD / DSP ·
low-precision numerics · vendor-agnostic accelerator runtimes

### Tech
Rust · C++ · MLIR / LLVM · C · Python

**Open to fixed-scope compiler / runtime engagements.**
